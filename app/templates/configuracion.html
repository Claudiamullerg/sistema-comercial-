Webhook para ManyChat esto es lo que pegas en el External Request

  1. En ManyChat, abre el flujo que se dispara con tu keyword (por ejemplo FRONTERA). Después del primer mensaje, añade una acción External Request (está en «Actions» → «External Request»; requiere plan Pro).
  2. Método POST. URL: {{ base_url }}/webhooks/manychat?secret={{ secret }}
  3. Header: Content-Type: application/json. Cuerpo (Body): copia el bloque de abajo. Los valores del Reel y la keyword los pone el flujo en los campos CRM_* justo antes (acción Set Custom Field), así el mismo bloque sirve para todos los flujos.
  4. Pulsa «Test request»: aquí abajo, en el registro, debe aparecer «nuevo …» en segundos. Guarda y publica el flujo.
  5. Repite el External Request en los otros puntos que importan: después de la respuesta a la pregunta inteligente (con "evento": "RESPUESTA") y después de un clic en tu enlace ("evento": "CLICK").
{
  "evento": "ENTRADA",
  "subscriber_id": "{{ '{{user_id}}' }}",
  "ig_username": "{{ '{{ig_username}}' }}",
  "name": "{{ '{{full_name}}' }}",
  "email": "{{ '{{email}}' }}",
  "phone": "{{ '{{phone}}' }}",
  "last_input_text": "{{ '{{last_input_text}}' }}",
  "ig_follows_account": "{{ '{{ig_follows_account}}' }}",
  "origen_tipo": "{{ '{{cuf_CRM_ORIGEN_TIPO}}' }}",
  "origen_contenido": "{{ '{{cuf_CRM_ORIGEN_CONTENIDO}}' }}",
  "keyword": "{{ '{{cuf_CRM_KEYWORD}}' }}",
  "automatizacion": "{{ '{{cuf_CRM_AUTOMATIZACION}}' }}",
  "respuesta": "{{ '{{cuf_CRM_RESPUESTA}}' }}"
}

Las variables entre llaves dobles se eligen con el botón «{ }» del editor de ManyChat (user_id = Contact ID, ig_username = Instagram Username, last_input_text = Last Input Text, cuf_CRM_RESPUESTA = tu campo personalizado CRM_RESPUESTA). También puedes marcar «Full Contact Data»: la app entiende ese formato igual.
